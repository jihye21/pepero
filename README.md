빼빼로 만들기 — SGJC 공유 데이터 압축
Three.js 기반의 빼빼로 꾸미기 웹 페이지입니다. 사용자는 초콜릿 색상과 막대 두께를 조정하고, 초코펜으로 그림을 그린 뒤 공유 링크를 통해 결과를 전달할 수 있습니다.

이 버전은 공유 링크에 포함되는 초코펜 스트로크 데이터를 줄이기 위해 SGJC(Surface-Generative Joint Compression) 형식의 인코딩을 적용했습니다.
주요 기능
- 3D 빼빼로 편집: 회전, 초콜릿 딥핑, 초코펜 드로잉, 먹기 모드
- 모양 사용자 지정: 베이스 초콜릿 색상, 펜 색상·굵기, 막대 두께 조절
- 초콜릿 굳히기: 현재 그린 초콜릿 스트로크를 고정
- 선물 링크 공유: 현재 설정과 스트로크 데이터를 URL에 인코딩해 공유
- 기존 링크 호환: 새 SGJC 형식이 아닌 기존 Deflate 압축 JSON 링크도 읽도록 구성

실행 방법
1. 웹 브라우저에서 엽니다.
2. Three.js와 OrbitControls를 CDN에서 불러오므로 인터넷 연결이 필요합니다.
3. 회전·딥핑·초코펜·먹기 모드를 전환해 빼빼로를 꾸밉니다.
4. 메뉴에서 색상과 굵기를 조정하고 선물하기 버튼으로 공유 링크를 복사합니다.
5. 링크를 열면 URL에 저장된 빼빼로 설정과 스트로크를 복원합니다.
공유 링크의 복사 기능은 브라우저의 Clipboard API를 사용합니다. 브라우저 보안 정책에 따라 HTTPS 또는 localhost 환경에서 실행해야 할 수 있습니다.

압축 방식 개요
공유 데이터는 다음 단계를 거칩니다.
1. 스트로크 단순화: Ramer–Douglas–Peucker(RDP) 방식으로 불필요한 중간 점을 줄입니다. 허용 오차는 펜 굵기를 고려해 정합니다.
2. 점 인코딩:
   - 원통형 막대 표면에 놓인 것으로 판단되는 점은 각도와 높이 중심의 표면 표현으로 저장합니다.
   - 그 외의 점은 양자화한 3D 좌표를 델타 인코딩해 저장합니다.
3. 정수 압축 표현: 좌표 차이 등은 가변 길이 정수로 기록합니다.
4. Deflate 압축: 바이너리 데이터를 Deflate로 압축합니다.
5. URL-safe Base64 변환: URL 쿼리 문자열에 넣을 수 있는 형태로 변환합니다.

새 인코딩에는 SGJ 매직 바이트와 버전 식별자를 사용해 기존 JSON 데이터와 구분합니다. 수신 측은 해당 식별자를 확인해 새 형식으로 디코딩하고, 식별자가 없으면 기존 압축 JSON 경로를 시도합니다.
공유 데이터에 포함되는 항목
- 베이스 초콜릿 색상
- 막대 두께
- 딥핑 깊이
- 막대 높이
- 스트로크별 색상, 굵기, 점 좌표
공유 데이터는 URL의 gift 쿼리 파라미터에 포함됩니다. 따라서 링크가 길어질 수 있고, 링크를 가진 사람은 해당 꾸미기 데이터를 볼 수 있습니다. 비밀 정보나 개인정보를 공유 데이터에 넣지 마세요.

사용 기술
- HTML / CSS / JavaScript
- Three.js r128
- Three.js OrbitControls
- 브라우저의 CompressionStream 및 DecompressionStream 지원 여부에 영향을 받는 압축 처리
- URL-safe Base64 인코딩

호환성 및 제한 사항
- 최신 브라우저 사용을 권장합니다.
- Three.js와 OrbitControls는 CDN에서 불러옵니다.
- 스트로크 단순화와 좌표 양자화로 인해 원본 그림과 미세한 차이가 생길 수 있습니다.
- 표면점 판정은 좌표에 기반한 휴리스틱이므로 모든 스트로크가 동일한 정밀도로 복원된다고 보장하지 않습니다.
- 압축률은 그림의 복잡도와 점 개수에 따라 달라집니다. 모든 입력에서 공유 URL이 반드시 짧아지는 것은 아닙니다.
- JavaScript 구문 검사와 단순 인코딩·디코딩 테스트를 수행했지만, 실제 브라우저별 렌더링과 다양한 기기에서의 전체 동작은 별도로 확인해야 합니다.
